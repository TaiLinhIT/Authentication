The client trusts public keys that ship with the application.

To provision this build:
1. In Warehouse License Studio open Settings and click "Export public keys".
2. Save the file as public-keys.json.
3. Copy it into this folder (next to the client .exe, inside a folder named Keys).

The file contains public keys only; it is safe to distribute.
Never place a private key (private-key.p8) on a customer machine.
